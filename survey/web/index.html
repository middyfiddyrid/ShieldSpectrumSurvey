AMBIENT REFERENCE SWEEP outside / vehicle at curb — TSCM standard practice

  

    
Run one full sweep OUTSIDE the premises before sweeping interior rooms.
    The correlation engine compares interior vs. exterior amplitude per signal — a signal
    meaningfully stronger inside is locally sourced, even in a "likely normal" band like 2.4 GHz.

BUG-FREQUENCY SCAN known surveillance bands only — focused depth

  

    
A focused sweep of only the bands covert devices are known to use —
    315 / 433 / 915 MHz ISM, DECT, 2.4 / 5.8 GHz Wi-Fi, GPS, and the cellular uplink blocks a
    GSM/LTE bug transmits in — skipping broadcast and general allocations entirely. The full time
    budget is spent on those bands, so each gets far deeper dwell and finer resolution than a
    full-spectrum sweep of the same profile. Run it like an interior sweep: omni antenna, both SMA
    ports in sequence.

PHASE DIRECTION FINDING B220 two-antenna bearing — coherent RX-A + RX-B

    
Unlike the amplitude "warmer/colder" hunt above, this reads the
      phase difference of the wavefront across two antennas and computes an actual
      bearing. Needs the B220 (two RX chains, shared LO) and both antennas on a bar a
      known distance apart.
      Two-element arrays have a front/back mirror — the true bearing and its mirror are
      both shown; rotate the bar to break the tie (the true one stays put).

ACTIVE PROBE (PING) transmit a stimulus, find what reacts — needs a 2TX/2RX radio

    

      ⚠ This TRANSMITS. It only finds devices that REACT to a ping (receivers,
      oscillators, junctions) — a "no response" is not a clean bill; run it
      alongside the passive sweep, never instead of it. Simultaneous stimulate-and-listen
      needs the B220 (2TX/2RX); it is bench-pending, not yet field-validated.
      Stay in bands you are authorized to transmit in (ISM 902–928 / 2400–2483.5 / 5725–5875 MHz).

    

      
      
      
      
      
      
    

    

  

  

    
PASSIVE EMANATION SCAN find the SILENT bugs by the RF they leak — no transmitting

    
Catches a covert camera/recorder that never transmits and won't react to a
      ping: its clock still leaks a comb of evenly-spaced tones. Needs an SDR (Pluto/B220),
      a close antenna, and a relatively quiet spot. A null result is one independent look, not
      a clean bill — run it alongside the sweep and the active probe.

WIRELESS DEVICE INVENTORY rule out client-owned WiFi / Bluetooth devices

  

    
Scan with the laptop's own adapters, then walk the list with the client:
    mark each device they account for as OWNED. Anything loud (≥ −55 dBm) and unowned
    is highlighted — those are the 2.4 GHz hits to chase, not the client's soundbar.

    

      
      
      
      
    

    

  

  

    
BLUETOOTH DETAIL SWEEP every advertiser, fully identified — trackers first

    
Standalone read (not saved to the inventory). Every device's MAC
    address type, vendor, decoded advertisement, and any location tracker
    (AirTag / Tile / SmartTag) it looks like. Use SCAN BLUETOOTH LE above to persist a
    device and mark it client-owned.

    

    

  







  
CALIBRATION / EXPERIMENT MODE run at the shop, not client sites

  

    
Runs the same segment under each strategy (Normal raw, Average×N, Max×28,
    MaxHold×T, varying spans) against a known test source, then persists the winning per-band
    configuration to config.yaml — production sweeps get tuned to this exact unit.
